# Native backend: store into a 2-D array with computed `mod`/`and` indices writes the wrong value (`t7 0` instead of `t7 1`)

Kind: miscompile. Backend: native (`nimony n`), with and without `-d:danger`. Known-as: new.
Fuzzer: the most common native mismatch shape — `mat[...]` wrong in 1000047, 1000065, 1000079, 1000123, 1000130,
1000157, 1000159, 1000189, 1000199, 1000208 (10 of 27 native mismatches); baseline 500132 (`arr[x mod y]` store)
looks like the same family. Hand-simplified variants (no object, fewer locals) do NOT reproduce, so it depends on
register pressure; this is the delta-reduced program.

Repro (`nmat_min.nim`, 15 lines):
```nim
import std/[syncio, math]
type B = object
  q: array[4, uint64]
  d: float64
  e: int8
proc t7(p0: uint64; p1: float64; p2: uint32; p3: float32; p4: int32) =
  var a0: uint64 = p0
  var a4: int32 = 0'i32
  var b0 = B(q: [p0, p0 xor 1'u64, 0x7FFFFFFFFFFFFFFF'u64, 9'u64], d: p1, e: (-100'i8))
  var mat: array[3, array[4, int32]] = [[p4, 1'i32, -2'i32, 3'i32], [(not (1'i32)), p4 * 3'i32, 0'i32, high(int32)], [low(int32), 7'i32, p4 - 1'i32, int32(a4)]]
  mat[(b0.q[3]) mod 3'u64][((uint64((1'i16)) and (a0 mod (0x0000000000000002'u64 or 1'u64)))) and 3'u64] = int32(uint8((p0 mod (0x0000000100000000'u64 or 1'u64)) and 255'u64))
  echo "t7 ", cast[uint32](mat[0][0])
proc main() =
  t7(0x8000000000000000'u64, -1e300, 0xADB6C093'u32, 0.0'f32, (0'i32))
main()
```
Command: `nimony n --nimcache:nc nmat_min.nim && nc/n/*/nmat_min`

Actual (native): `t7 0`. Expected (C): `t7 1` (index [9 mod 3][1 and (2^63 mod 3)] = [0][0]; value
uint8((2^63 mod (2^32+1)) and 255) = 1).

Phase: arkham x64 — the store `(asgn (at (at mat I) J) V)` with three magic-division `mod`s in flight; the value or
the address is computed from a clobbered register (same area as finding 10's staging-register exhaustion).
