# Native backend with the optimizer: a keepovf operation folded to a constant reports a stale overflow

Kind: miscompile. Backend: native, `-d:danger`. Known-as: bug-reports/89-native-opt-folded-keepovf-stale-flag.
Fuzzer: 1000129, 1000161: `ckmul_int64((i64v - i64v), (-9223372036854775807'i64) * a5)` returns `0 xor 85` (the
helper's overflow marker) — the non-keepovf multiplication in the argument overflowed, then the folded `0 * x`
inside keepovf read its flag. Reduced repro (red/n_1000129): C prints `t8 0`, native `t8 85`. Not re-filed.
