# 02 — inliner substitutes a `(deref p)` / local argument into the body, so the callee reads it AFTER its own writes

Kind: **miscompile**, in the DEFAULT build (no `--opt`, no `-d:release`), C and native backends alike.
Known-as: **new** (nothing in bug-reports; no upstream issue found for "inliner argument").
Fuzzer signatures: `mismatch [imi]` (c_1173), `mismatch [none]` (c_1273). The optimizer's
`imi` pass reuses the same splice code, so `--opt:speed` builds hit it at more call sites
and the fuzzer saw it as an opt-vs-base difference; the minimized repros below are wrong in both builds.

## Minimized repros

`inl1.nim` (by-value param, its argument `p[]` points at a global the callee writes):
```nim
import std/syncio

var g = 5

proc f(z: int): int =
  {.cast(assumeSync).}:
    g = 1
    result = z + g    # z is the value of the argument at the call: 5

proc main() =
  {.cast(assumeSync).}:
    let p = addr g
    echo f(p[])       # expected 6
main()
```

`inl2.nim` (bare local argument, written by the callee through a pointer):
```nim
import std/syncio

proc f(z: int; p: ptr int): int =
  p[] = 1
  result = z + p[]   # z is the argument's value at the call: 5

proc main() =
  var x = 5
  echo f(x, addr x)  # expected 6
main()
```

## Command
```
nimony c -r inl1.nim               -> 2
nimony c -r --opt:speed inl1.nim   -> 2
nimony n -r inl1.nim               -> 2
nimony c -r inl2.nim               -> 2   (same for --opt:speed and n)
```
With `{.noinline.}` on `f` both print `6`.

## Actual / Expected
Actual `2`, expected `6`. Generated C for `inl1.nim` (base build) — `z` became `(*pa)`, read after `g = 1`:
```c
g0_0 = ((NU64)1ull);
resultX60Qh_23 = ((NU64)((*paX60Qh_18) | g0_0));
```

## Phase at fault
hexer intra-module inliner, `src/hexer/intramodinliner.nim`, `bindingsFor`: a read-only by-value
parameter is replaced by its argument at every use (no `(var :p T arg)` copy) when the argument is
- `isStableDerefArg` — `(deref S)` for a bare symbol `S`. Its doc comment argues safety from "the
  inlined body cannot assign the caller's pointer", but the hazard is the POINTEE: the body may write
  it through a global (`inl1`) or through another pointer/var parameter;
- a bare caller LOCAL symbol — "the inlined body only ever assigns fresh-renamed locals, never a
  caller local", which is false once the caller passed that local's address in another argument (`inl2`).
Both substitutions need the same `opaqueEffects`/`bodyIsCallerReadOnly` guard the path-argument case
already has (no store through a pointer, no store to a global, no call), or the copy must stay.
shoggoth's `imi` (`src/lengc/shoggoth/intermodinliner.nim` → `intramodinliner.trIntra`) inherits it.
Fuzzer seeds: out/c_mismatch_1173.* (`g0 = e2(addr g0, pb, pa[])`, pa = addr g0) and
out/c_mismatch_1273.* (`a0 = e2(pb, pb, pb[])`, pb = addr a0; opt C shows `z shr` → `(*pb_0) >> …`).
