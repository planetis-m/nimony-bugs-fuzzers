# 01 — `--opt:speed` CSE: a load through a parameter survives a store to memory the parameter may point at

Kind: **miscompile** (C and native: Leng-level rewrite). Known-as: **new** (not in bug-reports; nim-lang/nimony#2930 is a different, call-related bug).
Fuzzer signature: `mismatch`, passes bisect: `cse` (also `imi,cse` when the callee is inlined).
First found by optfuzz at 54 s (seed 500027), then by most later C-mode mismatches.

## Minimized repro (var param + global; no pointers, no `addr`)

`cse2gv.nim`:
```nim
import std/syncio

var g = 5

proc f(x: var int): int {.noinline.} =
  {.cast(assumeSync).}:
    let a = x
    g = 0          # x is g: this writes x
    result = a + x # expected 5 + 0

proc main() =
  {.cast(assumeSync).}:
    echo f(g)      # expected 5
main()
```

Two-pointer variant (`cse2.nim`):
```nim
import std/syncio

proc f(p, q: ptr uint64): uint64 {.noinline.} =
  let a = q[]       # load q[]
  p[] = 0'u64       # store through p, which aliases q
  result = a + q[]  # q[] must be reloaded: 5 + 0

proc main() =
  var x = 5'u64
  echo f(addr x, addr x)   # expected 5

main()
```
Also: `proc f(x: var uint64; y: var uint64)` called as `f(p[], v)` with `p = addr v` (sem's
"mutable argument aliases" check does not see through `p[]`), and `proc f(p: ptr uint64)` with a
store to the global `p` points at (`cse2g.nim`, `cse2v.nim`). All in /home/ageralis/Projects/nimony-fuzz/opt/old/min/.

## Command
```
nimony c -r cse2gv.nim               -> 5

SHOGGOTH_DISABLE=cse nimony c -r --opt:speed cse2.nim  -> 5
```

## Phase at fault
shoggoth CSE, `src/lengc/shoggoth/cse.nim`: `invalidateForStore` → `clobberPath` →
`expressionOverlaps` → `mayOverlap`. A cached load is only killed when BOTH the path rule and
`classesMayAlias` (the intra-proc union-find partition from `aliasing.nim`) say it may overlap.
For two indirect paths (`(deref q)` vs `(deref p)`) and for an indirect read vs a direct write to a
global (`(deref x)` vs `g`), `byPath` is true but `classesMayAlias(q, p)` / `(x, g)` is false,
because the partition only joins symbols connected by an assignment inside the body. Two distinct
pointer/var PARAMETERS, or a parameter and a global, start in different classes although the
caller may pass aliasing addresses. The partition must treat parameters (and globals / anything
escaped) as one "external memory" class, i.e. `classesMayAlias` must return true when both roots
can be reached from outside the body.
