# 04 — A write through `addr x` passed to a `ptr` parameter keeps the old facts about `x`

kind: **accepts-invalid (unsound)**. known-as: **bug-reports/87-addr-write-false-proof-index** (same root; 87
shows `let p = addr x; p[] = v`, the fuzzer mostly hits the call form `viaPtr(addr x, v)` and a field target
`addr o.f`, which 87's notes list as "not reproduced"). 87 itself still reproduces on 0305d6c6.

## Minimized repro (fuzzer output, reduced by hand to a standalone file: `repro/r04_addrarg.nim`)

```nim
{.feature: "staticContracts".}
import std/syncio
type Obj = object
  f: int
proc viaPtr(p: ptr int; v: int) = p[] = v
proc g(o: var Obj; s: seq[int]): int =
  result = 0
  if o.f >= 0 and o.f < s.len:
    viaPtr(addr o.f, 1000000000)
    {.assert: o.f < s.len.}       # accepted
    result = s[o.f]               # accepted: no check left
var o = Obj(f: 1)
echo g(o, @[1, 2, 3])
```

Command: `bin/nimony c -r --nimcache:nc r04_addrarg.nim`

Actual: compiles, then crashes with a segmentation fault (no bounds error).
Expected: `cannot prove assertion` / `cannot prove contract: i < s.len and 0 <= i`, as for `o.f = 1000000000`.

## False fact derived

`0 <= o.f < s.len` (resp. `0 <= x < N`) still holds after the callee stored through the pointer.

## Rule at fault

`src/nimony/contracts_fir.nim: analyseCallArgs` (the argument loop around lines 4400-4450): a location is added
to `mutatedRoots` — and its facts dropped by `invalidateFactsAbout`/`invalidateDerivedFrom` after the call — only
when the *formal* is `var`/`out` (`if pk in {MutT, OutT}:`). An explicit `(addr x)` bound to a `ptr T` formal adds
nothing: `addr` is treated as "the unchecked escape hatch" (`HasAddr`), so the facts about `x` survive the call.
Report 87 is the same omission for the store `p[] = v` (a `DerefX` destination has no root variable).
