# 08: A local inline iterator declared inside the body of a `for` over an inline iterator: `coro_transform state != -1`

## Repro (`r08_local_inline_iter_in_for_body.nim`, file: findings/repros/r08_local_inline_iter_in_for_body.nim)

```nim
import std/syncio
type CT = proc (y: int): int {.closure.}

iterator it(): int {.sideEffect.} = yield 1
proc u() =
  for x in it():
    iterator li(a: int): int {.sideEffect.} =
      yield a
    for y in li(x): echo y
u()
```
