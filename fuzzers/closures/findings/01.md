# 01: a local `.closure` iterator inside a `.closure` iterator crashes the hexer

Found during generator calibration (before the timed run); the campaign ran with `--avoid citer-in-citer`.

## Repro (`b2.nim`)

```nim
import std/syncio

iterator outer(): int {.closure, sideEffect.} =
  iterator inner(): int {.closure, sideEffect.} =
    discard
  yield 2

for x in outer():
  echo x
```

Command: `nimony c -r --nimcache:<dir> b2.nim`

## Actual

```
Error: unhandled exception: nifcore.nim(1281, 3) `c.rem == 0` into: body did not consume all 151 children (left 60) [AssertionDefect]
nifmake: command failed (exit code 1): .../bin/shoggoth c ...
```

With `{.closure, raises, sideEffect.}` on both iterators (and the loop in a `try`) the crash is instead
`[Bug] could not find symbol: `coroResult.0.<mod>` (also shoggoth). Using `inner` (`for x in inner(): yield x`)
crashes the same way.

## Expected

Prints `2`. A nested closure iterator is accepted by nimsem; the closure iterator tests only nest one inside a proc.

## Phase at fault

hexer, `iterinliner.rewriteClosureIter` (src/hexer/iterinliner.nim:266): it runs `transformStmt` over the outer body,
whose `IteratorS` case routes the nested `.closure` iterator into `rewriteClosureIter` again; the nested iterator's
`coroResult` local and its body then reach later passes inconsistently (cps / coro_transform see either an unconsumed
body or a `coroResult` symbol that was never declared in the frame). Exact function not confirmed (no debug build).

Kind: crash. Known-as: new (no match in ../bug-reports or nim-lang/nimony issues for "coroResult", "nested closure iterator").

## Variant via an inline iterator (repros/r01b_inline_iter_with_closure_iter_in_closure_iter.nim)

An inline iterator that declares and iterates a local `.closure` iterator, iterated from a `.closure` iterator, hits the
same assertion (`body did not consume all 151 children`); with `raises` it is campaign signature f09
`could not find symbol: coroResult.N` (29 hits).

```nim
import std/syncio
type CT = proc (y: int): int {.closure.}
iterator it(): int {.sideEffect.} =
  iterator li(): int {.closure, sideEffect.} =
    yield 5
  for x in li(): yield x
iterator ci(): int {.closure, sideEffect.} =
  for x in it():
    yield x
for x in ci(): echo x
```
Expected `5`.
